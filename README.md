# MetalCalc Pro v2.0

Arabic RTL-friendly Android native app for metal fabrication calculations.

Included:
- Sheet weight
- Square/rectangular tube, round tube, angle and flat bar
- kg/m and total weight
- Material density catalog
- Bend Allowance / Bend Deduction / K-Factor
- Two-flange outside-dimension blank estimate
- Cutting, bending, welding, painting, scrap and profit pricing
- Corrected unit tests

Important:
The bend formulas are engineering calculation helpers. For production, verify K-factor/radius against the actual material, tooling and press-brake process.

Build:
1. Open the project in Android Studio.
2. Sync Gradle.
3. Run tests.
4. Build > Generate App Bundles or APKs > Generate APKs.

Package: com.metalcalc.pro
Version: 2.0.0
